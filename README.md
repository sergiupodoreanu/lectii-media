# Culoare și LED prin DMX

Instruire practică, 30 de ore, clasa a XII-a — Liceul Tehnologic „Grigore C. Moisil” Buzău.

Zece ateliere în jurul unei bare LED FOS Bar 24×4 W RGBW comandate prin DMX cu interfața ADJ myDMX 3.0: comanda culorii, cablare DMX, canale și adrese, amestecul culorilor, armonii, modul 8CH, scene și chase, proiect final.

Pagina lecțiilor: se deschide `index.html` sau adresa GitHub Pages a acestui repo.

Prof. Sergiu Podoreanu

## Alte lecții din acest depozit

- **Fișierele PDF — 7 lecții** (`pdf.html`) — modulul „Montajul și verificarea documentelor digitale”, clasa a XII-a, 7 ore: ce este un PDF și cum arată înăuntru; cele patru căi de generare; standardele PDF/X, PDF/A, PDF/UA; pregătirea pentru tipar (bleed, tăiere, zonă sigură, cu simulator); culoarea și profilele ICC; verificarea (preflight) și exportul PDF/X‑1a din Scribus; PDF-ul interactiv și proiectul final (pliant în două variante). Fiecare lecție are fișă de lucru; testul unității e la lecția 7. Materiale însoțitoare: `exemplu-minim.pdf` (PDF de o pagină, scris de mână, pentru „autopsie” în Notepad++), `scripts/fa_pdf_minim.py` (îl generează), `scribus/` (scripturi care construiesc șabloane Scribus: afiș A3, pliant A4 în C, pliant A4 în Z — se rulează din *Script → Execute Script*, apoi *File → Save as Template*).
