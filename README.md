# Culoare și LED prin DMX

Instruire practică, 30 de ore, clasa a XII-a — Liceul Tehnologic „Grigore C. Moisil” Buzău.

Zece ateliere în jurul unei bare LED FOS Bar 24×4 W RGBW comandate prin DMX cu interfața ADJ myDMX 3.0: comanda culorii, cablare DMX, canale și adrese, amestecul culorilor, armonii, modul 8CH, scene și chase, proiect final.

Pagina principală (`index.html`) e un cuprins cu toate unitățile. Lecția DMX e acum în `dmx.html`, iar unitatea despre PDF în `pdf.html`.

Prof. Sergiu Podoreanu

## Alte lecții din acest depozit

- **Fișierele PDF — 9 lecții** (`pdf.html`) — modulul „Montajul și verificarea documentelor digitale”, clasa a XII-a, 9 ore: PDF-ul de zi cu zi (deschis, citit, modificat cu unelte gratuite); ce este un PDF și cum arată înăuntru; cele patru căi de generare; standardele PDF/X, PDF/A, PDF/UA; pregătirea pentru tipar (bleed, tăiere, zonă sigură, cu simulator); culoarea și profilele ICC; verificarea (preflight) și exportul PDF/X‑1a din Scribus; PDF-ul interactiv și proiectul final (pliant în două variante). Fiecare lecție are fișă de lucru; testul unității e la lecția 8; lecția 9 (bonus) — forensică de metadate și confidențialitate (recunoașterea și dezarmarea unui PDF care „sună acasă”), cu mostrele inerte `demo-metadate.pdf` și `demo-openaction.pdf` și generatoarele lor din `scripts/`. Materiale însoțitoare: `exemplu-minim.pdf` (PDF de o pagină, scris de mână, pentru „autopsie” în Notepad++), `scripts/fa_pdf_minim.py` (îl generează), `scribus/` (scripturi care construiesc șabloane Scribus: afiș A3, pliant A4 în C, pliant A4 în Z — se rulează din *Script → Execute Script*, apoi *File → Save as Template*).
- **Markdown de bază** (`markdown-baza.html`) — modulul „Montajul și verificarea documentelor digitale”, clasa a XII-a, 3 ore: text simplu și text formatat, primul fișier `.md`, paragrafe, titluri, evidențieri, liste, legături, imagini, citate, cod, caractere speciale, greșeli frecvente, test. Fișa de laborator (`markdown-baza-fisa.html`): un articol pentru revista clasei, pornind de la un text nemarcat. Fișier-exemplu: `exemplu-baza.md` (folosește `imagini/schita.png`).
- **Markdown avansat** (`markdown-avansat.html`) — același modul, 3 ore: tabele cu aliniere, liste de sarcini, note de subsol, blocuri de cod, antet de metadate, formule, diagrame Mermaid, conversia cu Pandoc în Word și HTML, README pe GitHub, verificarea documentului, test. Fișa de laborator (`markdown-avansat-fisa.html`): documentul de proiect al unui afiș. Fișier-exemplu: `exemplu-avansat.md`.
- **GitHub și GitHub Pages** (`github.html`) — același modul, 3 ore: ce este GitHub (depozit, commit, versiune), crearea contului și siguranța lui, depozitul de teme organizat pe foldere, încărcarea, înlocuirea și ștergerea fișierelor din browser, istoricul, README, publicarea site-ului cu GitHub Pages, pagina `index.html`, predarea temei prin link, reguli de publicare, greșeli frecvente, test. Fișa de laborator (`github-fisa.html`): portofoliul online propriu, cu prima lucrare publicată. Răspunsuri pentru profesor: `github-raspunsuri.html` (nelegată din cuprins).
