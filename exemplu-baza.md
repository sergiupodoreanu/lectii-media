# Ghid scurt: alegerea fonturilor pentru un afiș

Un afiș se citește **de la distanță** și **în câteva secunde**. Fonturile se aleg astfel încât mesajul să fie înțeles imediat.

## Reguli de bază

- Cel mult **două familii de fonturi** pe un afiș.
- Titlul se scrie cu un font *sans-serif* (fără serife), ușor de citit de departe.
- Contrast puternic între text și fundal.

## Pașii de lucru

1. Se citesc cerințele clientului.
2. Se aleg fonturile:
    - un font pentru titlu;
    - un font pentru textul mărunt.
3. Se verifică licența fiecărui font.
4. Se face o probă de tipar la dimensiunea reală.

## Dimensiuni recomandate

Pentru un afiș A3 privit de la 2–3 metri:

- titlu: 90–120 pt;
- subtitlu: 36–48 pt;
- text informativ: 18–24 pt.

> Un afiș bun se înțelege fără a fi citit până la capăt.
>
> — din regulile atelierului

## Surse de fonturi gratuite

Fonturi cu licență liberă se găsesc pe [Google Fonts](https://fonts.google.com "Biblioteca Google Fonts"). Adresa completă: <https://fonts.google.com>.

Fișierul unui font are extensia `.ttf` sau `.otf` și se instalează cu dublu clic.
