Fișă de laborator – Portofoliul online

GitHub și GitHub Pages · Clasa a XII-a · Producție media · 2 ore

Cuprins Lecția: GitHub
Lucrarea: se creează contul GitHub, depozitul portofoliu-media și site-ul de portofoliu, în care se publică prima lucrare.
Necesar: browser, acces la adresa de email personală, o lucrare proprie de la lecțiile anterioare, în două fișiere: documentul final (PDF) și o imagine de prezentare (PNG sau JPG).
Rezultat predat: două adrese – a depozitului și a site-ului.
Înainte de a începe: pe calculatorul din laborator parola nu se salvează în browser. La sfârșitul orei se iese din cont: imaginea de profil (dreapta sus) → Sign out.

Sarcina 1 – Contul 15 min

  1. Se deschide adresa github.com/signup și se creează contul, după pașii din lecție. Cine are deja cont intră în el cu Sign in.
  2. Numele de utilizator se alege după regulile din lecție: serios, ușor de dictat, cu litere mici.
  3. Se confirmă adresa de email cu codul primit.
  4. Se deschide github.com/settings/emails și se verifică dacă este bifată opțiunea Keep my email addresses private.
  5. Numele de utilizator se trece în tabelul de la sfârșitul fișei.

Sarcina 2 – Depozitul 10 min

  1. Se deschide github.com/new și se creează depozitul portofoliu-media: Public, cu Add README activat și cu o descriere de un rând.
  2. Se notează adresa depozitului.
  3. Se răspunde în scris, în caiet sau într-un fișier de notițe: cine poate vedea fișierele din acest depozit și cine le poate modifica?

Sarcina 3 – Fișierul README.md 10 min

  1. Se deschide README.md și se apasă butonul cu creion.
  2. Conținutul se înlocuiește cu o prezentare scrisă în Markdown, care cuprinde:
    • un titlu de nivel 1 cu numele portofoliului;
    • un paragraf cu clasa, specializarea și liceul;
    • un titlu de nivel 2 „Lucrări”, urmat de o listă sau de un tabel cu lucrarea care urmează să fie încărcată.
  3. Se verifică în fila Preview.
  4. Se apasă Commit changes… și se scrie un mesaj de commit potrivit.

Sarcina 4 – Prima lucrare 15 min

  1. Pe calculator se creează folderul temei, cu nume scris după reguli (de exemplu tema-01-afis), iar în el se copiază documentul PDF și imaginea de prezentare.
  2. Fișierele se redenumesc după reguli: litere mici, fără spații, fără diacritice.
  3. Se verifică mărimea fiecărui fișier (clic dreapta → Properties). Se notează mărimile și se compară cu limita din lecție.
  4. Folderul se încarcă în depozit cu Add file → Upload files, cu un mesaj de commit potrivit.
  5. Se verifică în depozit că fișierele sunt în folderul temei, nu în rădăcină.

Sarcina 5 – Corectarea și istoricul 10 min

  1. Pe calculator, imaginea de prezentare se modifică vizibil (de exemplu se decupează sau i se schimbă mărimea) și se salvează cu același nume.
  2. Imaginea se încarcă din nou, în folderul temei, cu un mesaj de commit care spune ce s-a schimbat.
  3. Se deschide istoricul depozitului și se notează: câte commituri are depozitul și care este mesajul fiecăruia.
  4. Se răspunde în scris: unde a ajuns varianta veche a imaginii?

Sarcina 6 – Activarea GitHub Pages 10 min

  1. Se activează Pages: Settings → Pages, Deploy from a branch, ramura main, folderul / (root), Save.
  2. După câteva minute se reîncarcă pagina și se deschide site-ul cu Visit site.
  3. Se notează adresa site-ului.
  4. Se răspunde în scris: ce fișier din depozit este afișat acum ca primă pagină și de ce?

Sarcina 7 – Pagina index.html 20 min

  1. În rădăcina depozitului se creează fișierul index.html (Add file → Create new file), pornind de la codul din lecție (butonul Copiază codul).
  2. Se înlocuiesc datele din exemplu cu cele proprii: numele (în <title> și în <h1>), titlul lucrării, descrierea de un rând.
  3. Căile din src și href se scriu exact după numele folderului și ale fișierelor din depozit.
  4. Textul alternativ (alt) descrie ce se vede în imagine.
  5. Se face commit, se așteaptă publicarea și se reîncarcă site-ul (Ctrl+F5).
  6. Pe site se verifică: diacriticele, imaginea, legătura către PDF.
  7. Opțional: în blocul <style> se schimbă fontul și se adaugă o culoare pentru titluri, cu regulile de alegere a fonturilor și de contrast de la lecțiile anterioare.

Sarcina 8 – Verificarea 10 min

  1. Portofoliul se verifică după lista de mai jos.
  2. Adresa site-ului se dă unui coleg, care o deschide pe telefon și spune două observații (ce nu funcționează sau ce se poate îmbunătăți).
  3. Se fac corecturile, cu mesaje de commit potrivite.
  4. Se iese din cont: Sign out.
