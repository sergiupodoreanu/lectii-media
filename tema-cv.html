Temă – CV-ul meu în Markdown

Montajul și verificarea documentelor digitale · Clasa a XII-a · Producție media · temă pentru acasă

Cuprins Lecția: Markdown de bază Lecția: Markdown avansat Lecția: GitHub Modelul (.md)
Tema: pornind de la modelul de mai jos, se scrie în Markdown un CV propriu (curriculum vitae – prezentarea pe scurt a studiilor, a competențelor și a lucrărilor unei persoane) și se publică în portofoliul de pe GitHub.
Programe: VS Code sau editorul JotBird (în browser, fără instalare), browser.
Rezultat predat: adresa folderului tema-02-cv din depozitul portofoliu-media, cu CV-ul în trei formate: cv.md, cv.pdf, cv.html.
Fișierul este public. În CV se trec numai numele, clasa și liceul. Nu se trec adresa de domiciliu, numărul de telefon, CNP-ul, data nașterii sau adresa de email.

Cerința 1 – Fișierul

  1. În folderul portofoliului se creează folderul tema-02-cv (numărul temei se potrivește cu ordinea din portofoliul propriu).
  2. În el se creează fișierul cv.md, în care se copiază modelul.
  3. Se deschide previzualizarea alături de text: Ctrl+K, apoi V.

Cerința 2 – Datele proprii

  1. Toate datele din model se înlocuiesc cu date proprii și reale: nume, motto, „Despre mine”, școli și ani, competențe, proiecte, obiective.
  2. La „Proiecte” se trec lucrări făcute cu adevărat la orele de specialitate, cu programul folosit.
  3. Legăturile din model se înlocuiesc cu adresele proprii (profilul GitHub, site-ul portofoliului).
  4. În fișier nu rămâne niciun text din model: „Prenume Nume”, „utilizator”, „…”.

Cerința 3 – Structura

Structura modelului se păstrează. CV-ul predat cuprinde cel puțin:

  • un singur titlu de nivel 1 (numele) și cel puțin cinci titluri de nivel 2;
  • un tabel (Educație);
  • o listă cu buline și o listă numerotată;
  • o listă de sarcini (Obiective);
  • un citat, o linie orizontală și cel puțin două legături care funcționează.

Cerința 4 – Personalizarea

Față de model se adaugă cel puțin trei personalizări, la alegere:

Cerința 5 – Exportul în PDF și HTML

Același CV se exportă în încă două formate, cu editorul JotBird (editor Markdown care funcționează în browser, fără instalare și fără cont).

  1. Se deschide adresa jotbird.com/app.
  2. File → Import… – se alege fișierul cv.md. Textul apare în stânga, iar previzualizarea în dreapta (pe telefon previzualizarea poate fi ascunsă).
  3. File → Export as HTML – fișierul descărcat se redenumește cv.html.
  4. File → Print or save as PDF – în fereastra de tipărire, la Destinație se alege Salvare ca PDF, format A4; fișierul se salvează cu numele cv.pdf.
  5. Cele două fișiere se copiază în folderul tema-02-cv, lângă cv.md, și se deschid pentru verificare: cv.html în browser, cv.pdf în cititorul de PDF.
Ciornele din JotBird rămân numai în browserul calculatorului pe care s-a lucrat. Dacă CV-ul a fost modificat în JotBird, la sfârșit se face și File → Export Markdown, iar fișierul obținut înlocuiește cv.md. Butonul Publish nu se folosește la această temă: publicarea se face pe GitHub.

Cerința 6 – Verificarea și publicarea

  1. CV-ul se citește în previzualizare și se compară cu lista de mai jos.
  2. Folderul tema-02-cv se încarcă în depozitul portofoliu-media, cu un mesaj de commit potrivit.
  3. Fișierul se deschide pe GitHub și se verifică încă o dată cum se afișează.
  4. În README.md al portofoliului se adaugă tema în lista de lucrări, cu legături către cv.md și cv.pdf.
